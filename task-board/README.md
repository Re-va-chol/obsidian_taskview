# Task Board

A configurable task board and memo workspace for Obsidian.

## 0.5.0

- Drag task cards to reorder their visible positions.
- Drag memo topics to reorder them (pinned and unpinned groups are kept separate).
- Drag memo notes to reorder notes inside a topic.
- Settings changes refresh open Task Board, Memo, and Statistics views immediately.
- The “打开所有任务” stack remains fixed and is not draggable.
- The all-tasks stack is visually larger and uses opaque card layers.

## Development

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```
